## 🚀 Featured Deployments & Flagship Systems

### 🔌 **[StackBridge-MCP](https://github.com/ZainUlAbideen02)** · *Open-Source Model Context Protocol Server*
**Stack:** `Python` · `FastMCP` · `AST Parsing` · `TypeScript` · `Next.js` · `FastAPI`
* Designed and published an open-source MCP tool server enabling LLM agents to map, trace, and validate cross-stack AST contracts between FastAPI backends and Next.js frontends.
* Eliminates runtime type desynchronization by serving real-time schema diffs and route registries directly to agent contexts.

### ⚖️ **[LeaseSight](https://github.com/ZainUlAbideen02)** · *Enterprise Legal Document Auditing Engine*
**Stack:** `Next.js` · `FastAPI` · `LangGraph` · `Pinecone/pgvector` · `Groq LPU` · `Stripe`
* Architected a multi-agent auditing platform processing complex unstructured commercial leases via hybrid search (dense embeddings + BM25 keyword re-ranking).
* Engineered a visual grounding engine mapping LLM-flagged compliance liabilities to pixel-level PDF bounding box coordinates in real time.

### 🛡️ **Autonomous Social Integrity Browser Extension**
**Stack:** `TypeScript` · `Transformer NLP` · `WebExtensions API` · `FastAPI`
* Built a client-side DOM processing engine that intercepts dynamic comment streams and runs sub-100ms toxic classification.
* Employs localized sentiment filtering and reversible client-side obfuscation without degrading page load metrics.

### 💳 **Low-Latency Transaction Fraud Classification Pipeline**
**Stack:** `Python` · `XGBoost` · `SMOTE` · `Scikit-Learn` · `FastAPI` · `Docker`
* Implemented a high-throughput transaction scoring pipeline with synthetic balancing for extreme positive-case scarcity (0.17% fraud rate).
* Containerized with strict schema evaluation to maintain sub-20ms p99 inference latency under batch payloads.
